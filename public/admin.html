Webhook

Tudo que a Asaas mandou para este checkout. Evento que o código ainda não trata aparece aqui como não mapeado — é assim que se descobre que a Asaas passou a mandar algo novo. O payload não é guardado: só o nome dos campos e os valores que não identificam ninguém.

Requisição que chegou no endereço do webhook sem o token certo. O token recusado nunca é guardado — só a hora, o IP e se veio algum token. A contagem é acumulada por hora; as amostras são apagadas depois de 30 dias.
